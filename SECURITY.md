# Security Policy

## Supported version

Security fixes are provided for the latest published release only.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting feature when it is enabled
for the repository. Do not publish exploit details, malicious `.rp` samples,
private project files, credentials or personal information in a public issue.

Include:

- affected version
- Windows version
- minimal reproduction steps
- impact assessment
- a sanitized sample or hash when relevant

If private reporting is unavailable, open a public issue containing no
sensitive details and ask the maintainer for a private contact channel.
