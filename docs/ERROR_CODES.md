# Axure Downgrade 错误码

错误提示统一包含三部分：

- **错误码**：用于定位失败阶段。
- **错误原因**：面向用户的简要说明。
- **详细信息**：相关路径、系统错误、桥接器异常或原始验证报告。界面不会再隐藏这部分内容。

## 静态降级错误

| 错误码 | 错误原因 | 常见处理方式 |
| --- | --- | --- |
| `ADG-1001` | 输出路径与输入 RP11 文件相同 | 更换输出文件名，禁止覆盖源文件。 |
| `ADG-1002` | 找不到输入文件 | 检查文件是否被移动、重命名或删除。 |
| `ADG-1003` | RP9 安装目录无效 | 选择直接包含 `AxureRP9.exe` 的目录。 |
| `ADG-1004` | 输出文件不可写或正在被占用 | 在 Axure 中关闭目标文件，或更换输出位置/文件名。 |
| `ADG-1101` | 无法解析输入文件结构 | 输入可能损坏、不是有效 RP 文件，或使用了尚未识别的容器格式。 |
| `ADG-1102` | 输入文件不是 RP11 | 当前转换入口只接受主版本为 11 的 RP 文件。 |
| `ADG-1201` | 找不到转换桥接器 | 检查便携版 `bin` 目录是否完整，必要时重新解压软件。 |
| `ADG-1202` | 无法启动或连接转换桥接器 | 检查安全软件拦截、文件权限及桥接器依赖是否齐全。 |
| `ADG-1203` | 转换桥接器执行失败 | 查看错误详情中的完整 .NET/Axure 异常；通常与异常数据包或 RP9 组件加载失败有关。 |
| `ADG-1204` | 桥接器验证报告无法读取或解析 | 桥接器输出不完整、进程异常结束或程序文件版本不匹配。 |
| `ADG-1205` | 桥接器完成但未报告成功 | 查看详情中的桥接器状态值。 |
| `ADG-1301` | 无法回读转换后的文件 | 输出写入不完整、磁盘异常或生成容器损坏。 |
| `ADG-1302` | 输出版本不是 RP9 | 文件头版本改写未生效。 |
| `ADG-1303` | 输出完整性校验失败 | GZip 数据包数量、页面、设计文档、设置或静态属性的回读结果不满足安全条件。容器中的缩略图等二进制部件不再被误计为 GZip 包。 |
| `ADG-1304` | 转换完成后输出文件仍被占用 | 程序会自动等待约 2 秒并重试独占访问；仍失败时，关闭占用目标文件的程序后重试。 |

## 分析与界面错误

| 错误码 | 错误原因 | 常见处理方式 |
| --- | --- | --- |
| `ADG-2001` | 单文件分析失败 | 查看详情确认读取权限、文件是否存在以及格式是否有效。 |
| `ADG-2002` | 对照分析失败 | 检查两个待比较文件是否存在且可读取。 |
| `ADG-2101` | 程序没有获得打开保存对话框的权限 | 当前安装包权限清单不完整，请升级到修复后的版本。 |
| `ADG-9000` | 未分类错误 | 保留界面展示的全部详情，用于进一步定位和补充专用错误码。 |

## 进度阶段

进度弹窗根据实际转换流程更新，依次覆盖：路径检查、RP11 结构解析、RP9
序列化引擎初始化、容器读取、版本元数据降级、页面/元件/设计文档/设置转换、
数据包索引重建、文件写入和 RP9 回读验证。

百分比代表上述处理阶段的完成度，不代表输出文件字节数。处理大量页面或元件时，
“正在转换页面与静态元件”阶段可能持续较长时间，但进度会随数据包处理继续推进。
