# Axure Downgrade v0.1.7

首个面向 GitHub 公开发布整理的 Windows x64 便携版本

## 下载与运行

1. 下载 `AxureDowngrade-0.1.7-windows-x64-portable.zip`
2. 使用 SHA-256 文件校验压缩包
3. 完整解压，保持 `bin` 目录与主程序的相对位置不变
4. 双击 `AxureDowngrade.exe`
5. 首次转换时选择包含 `AxureRP9.exe` 的合法 Axure RP 9 安装目录

## 本版内容

- 全新的紧凑型 Fluent UI 桌面界面
- 1040×720 默认窗口内无滚动完成主要操作
- 支持选择、清除和更换 RP 11 文件
- 显示文件大小、修改时间和格式
- 圆角透明应用图标
- 本地文件处理，不上传原始工程
- 生成可编辑的 RP 9 静态工程
- 转换期间显示阶段与进度
- 失败时显示稳定错误码和详细原因

## 重要限制

- 目标是静态界面保真，不承诺保留交互行为
- 第三方或自定义组件、缺失字体和外部资源可能需要额外处理
- 必须自行提供合法安装的 Axure RP 9
