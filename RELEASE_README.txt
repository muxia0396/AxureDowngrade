Axure Downgrade v0.1.7
======================

System requirements
-------------------
- Windows 10 or Windows 11, x64
- Microsoft Edge WebView2 Runtime
- A lawfully installed copy of Axure RP 9

Quick start
-----------
1. Keep this executable and the bin directory together
2. Run AxureDowngrade.exe
3. Select one Axure RP 11 .rp file
4. Click Start Conversion
5. On first use, select the folder containing AxureRP9.exe

The source file is read locally and is not overwritten
